# 七猫内容审核红线

> 来源：七猫作家学院“审核小哥解读内容安全规范/内容创作规范”两篇 + 各篇散落红线。
> 目的：避免章节内容驳回、避免作品无法上架。过审存疑必查本文件。
> 男频都市/战神/末世题材是重灾区，写前务必对照。

## 性 / 色情（最高频驳回点）

- 禁止直接或间接描写性、性行为、性器官。
- 禁止描写人体暴露/裸体、过度刻画身材和敏感部位。
- 禁止性挑逗、性暗示动作语言。
- 禁止大量细致的拉丝吻戏、大篇幅性爱前戏等隐晦传色情。
- 禁止无助于推动情节/塑造人物的淫秽擦边内容；禁止为俗而俗、全本大量色情擦边作卖点。
- 禁止先奸后爱——男主主动对女主实施强奸/迷奸/诱奸发生关系作开篇剧情。
- 禁止开篇以被下药/醉酒制造狗血一夜情时过度强化“性”与“钱”的关系（卖身救母/卖初夜救爹/代孕救弟+下药发生关系=美化犯罪）。
- 男频种马文：见一个收一个、凡女性必发生关系，近似黄书，违规。

## 暴力 / 血腥 / 恐怖

- 禁止详细描写渲染恐怖血腥场景、过度生理痛苦、精神歇斯底里致读者不适。
- 禁止详细可模仿的杀人过程：分尸、吃人肉、肢解、凌迟割肉，且不可作连续性标题。
- 判定看题材+背景：古代战场砍头 vs 现代街头捅人概念不同；现代都市犯罪/报复类虐杀审核更严，减少篇幅细节。
- 死婴喂狗、流产婴儿肉块、现代背景砍头血柱喷泉等=违规。
- 禁止细致描写黑恶势力群殴械斗、凶杀、暴力催债、招打手、雇凶杀人。
- 禁止刑侦/虐恋文细致展示残酷恐怖犯罪过程及肉体精神虐待；追妻火葬场男主阴鸷暴戾、对女主言语侮辱/人身伤害/精神虐待严管。

## 主角三观 / 目无法纪（男频都市重灾区）

- 禁止主角反人类反社会人格、目无政府法纪、大量杀戮虐待屠杀。
- 都市法制背景下：当着警察面杀看不起自己的人、踩断普通人/保安手臂、让记者手臂爆炸=违规；都市背景杀虚构的武者/异能者/修仙者风险不大。
- 禁止塑造主角极度猥琐低俗（见女人就想捏/想睡、心思淫邪意淫打擦边）。
- 禁止吹捧主角违法乱纪、个人准则凌驾法律、不辨是非以恶为荣（“够狠警察也不敢动你”）。
- 禁止主角靠撒谎/猥亵女性/偷盗/辱骂换超能力或奖励的系统文（偷内裤给钱、气哭老奶奶给钱、吃狗屎换功法）。
- 禁止宣扬拜金/不劳而获/金钱至上/炫富仇富/否定努力（睡觉系统给钱、打赏女主播 1 亿、一夜暴富）。
- 禁止过度表达仇恨、宣泄对社会不满；禁止角色靠自杀/自残逃避现实来重生/穿越/获异能。

## 国家 / 政治 / 公职

- 禁止以任何形式攻击批判诋毁嘲讽抹黑中国共产主义/社会主义/国家法律法规/政治理念与政策（古代权谋、男频都市随意讨论时局政治）。
- 军政身份主角/配角不可暴力执法、权色交易、贪污腐败；不可过度个人英雄主义打政府/国家的脸、抹黑政府；不可大量打脸反转丑化矮化执法者。
- 反派可为执法者但违规行为须受法律制裁；不可影射真实人物事件；不能以单个案例映射整个部门/群体为反面；不可写执法人员迫于暴力金钱下跪、跪舔献殷勤。

## 国家安全 / 民族 / 国际关系（男频战神/末世重灾区）

- 禁止影射任何与“中国”有关的敏感事件（边境冲突、领土纠纷、敏感历史、恐怖事件）——如龙国 vs 阿三国边境冲突映射中印。
- 禁止主角/“中国”蓄意报复侵略侮辱破坏真实他国、发动现代战争屠杀平民；禁止男主统一全球称霸世界奴役真实国家。
- 华夏/龙国（中国）、美丽国（美国）、棒子国（韩国）、樱花国/岛国（日本）过度映射+意淫剧情违规（让岛国首相跪下吃屎、炸自由女神像等）。
- 禁止对自然灾害/重大事故庆祝戏谑冷嘲（丧尸病毒映射新冠、“岛国又地震怎么不全沉了”）。
- 禁止使用真实恐怖组织名称（IS）、演绎真实恐怖事件（911、昆明火车站等）；禁止人体炸弹、自焚、斩首、破坏真实建筑。允许架空虚构恐怖组织作情节推动（如卧底打击犯罪）。

## 历史 / 英烈 / 传统文化

- 禁止一切历史虚无主义：丑化英雄（质疑黄继光、邱少云）、美化汉奸、美化侵略、否定革命/党的领导/新中国成就。穿越重生架空审慎区别对待。
- 禁止不尊重史实的抗日/解放战争题材；七猫禁止上架抗战文（名家写实征文另议）。
- 禁止带不合逻辑系统/外挂穿越重生到抗战、解放战争、文革等敏感时期（空间带现代面包牛奶救文革父母=亵渎）。
- 禁止歪曲贬低民族优秀传统文化、侮辱扭曲古代历史人物（岳飞穿金俘服饰）。
- 禁止角色获真实唯一指代性荣誉（杂交水稻之父、两弹一星、共和国勋章）；真实著作/影视/歌曲/艺人/企业只可借用渲染气氛，须虚拟化称呼，禁篡改盗用版权。

## 宗教 / 迷信

- 禁止诋毁扭曲嘲讽丑化道/佛/基督新教/天主教/伊斯兰教及其信徒。
- 禁止邪教组织及活人献祭/屠宰等；禁止宣扬人尸恋、冥婚作书名主要内容。
- 灵异文不可让读者误信封建迷信为真实，不造谣传谣。

## 未成年（现代都市背景风险最高，玄幻古代修仙风险小）

- 禁止未成年人婚姻/性行为、师生恋早恋怀孕生子。
- 禁止未成年参与校园黑道/黑社会/枪械/赌博/迷信、与夜店酒吧卖淫挂钩、使用烟酒。
- 现代养成系言情禁止主角对未成年人意淫/性幻想/性引诱。
- 禁止将成人女主刻意写得像未成年（“只有十五六岁”“萝莉”“双马尾”“童颜巨乳”+行为心理接近儿童）。
- 都市后宫文有意无意提“后宫是高中生/初中生/青涩小嫩女”再上床=违规。
- 禁止诱导未成年暴力/自杀/霸凌/自残/愤世/抑郁/丧文化/厌学/流浪/恋黑恋暴。

## 低俗脏话（很常见）

- 禁止大量低俗谩骂脏话（含谐音）发泄情绪。
- 带性器官的脏话及谐音变体一律不通过。
- “草/艹/卧槽/特么”语气词风险较小；“狗日的/麻痹的/狗逼的”视情节少量可过、不可满屏；“他妈的”非变体表语气可过、也不可满屏。

## 题材级红线（选题阶段就要规避）

- 杜绝涉黄、涉政、涉黑、低俗、三观不正、违背公序良俗。
- 需规避：校园霸凌、耽美、未成年早恋、血腥暴力、拜金主义。
- 衍生/同人题材需经正式版权授权，慎重选择。

## 本书（惹错人了，我只是个保安）特别提醒

- 都市现实题材 + 保安功夫高手：主角出手对象优先是地头蛇、地下拳场、灰色安保、资本打手等“灰黑/虚构势力”，不要当众重伤/杀害普通人、警察、记者、保安。
- 沈砚秋是女警/特勤：执法者形象不可被反复丑化、矮化、跪舔；其违规同僚须受法律制裁，不能以个案抹黑整个警方系统。
- 资本集团反派的违法行为最终要落到“受制裁”，不能塑造成“主角靠更狠的违法压过去”的以恶制恶。
- 林野的暴力必须服务危机解决并承担现实后果（监控、舆情、追责），不能写成法外私刑爽感。
