# 七猫检查清单

写前：
- 本章功能是什么？（开钩 / 推进 / 爆发 / 过渡 / 感情 / 解谜 / 改稿）
- 主角本章目标（短期）是什么？长期目标拉着的是什么？
- 阻碍/对手/代价是什么？
- 本章要改变哪个变量？（信息 / 情绪 / 局势 / 关系）
- 本章爽点/情绪落点在哪？（七猫要求尽量每章一个）
- 章末钩子是什么？

写后：
- 是否可以被整章跳过？
- 目标是否迟到？主角是否全程被动被剧情推着走？
- 冲突是否只有口头“很难”，没有具体对手/代价/时间压力？
- 解释是否太多？背景是否大段平铺直叙？
- 爽点是否无反馈？（缺旁人反应/敌人代价/局势改变）
- 结尾是否平收、没留钩子？
- 是否踩中本题材的核心看点？（平淡的根因是没踩中类型契约，不是事件不刺激）
- 是否触碰审核红线？（存疑必查 audit.md）

签约/过稿前（开篇 1-3 万字自检，七猫编辑只看开篇）：
- 第一眼能否看出主角是谁、核心困境/目标是什么？
- 是否展现核心卖点、确立核心冲突？
- 是否抛出能撑 10-20 万字的大悬念？
- 开篇是否紧扣书名+简介（强关联）？
- 对比同类书，我的开篇优势在哪？
- 读者能否一口气从头看到尾不停顿？
- 关联性是否够强？（关联性差=读者觉得不知所云，连签约都难）

自检模板：
```text
七猫章节自检：
- 功能：开钩 / 推进 / 爆发 / 过渡 / 感情 / 解谜 / 改稿
- 首屏是否出现目标/冲突/异常/危机/悬念/金手指之一？
- 目标、阻碍、变化、反馈、章末钩子是否都在？
- 本章是否至少一个爽点或情绪落点？
- 是否踩中本题材核心看点？
- 是否过审（性/暴力/三观/国家/未成年/低俗）？
- 标题、简介、正文是否一致？
```
