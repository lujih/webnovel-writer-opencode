# 七猫钩子与期待感

## 钩子五层级

- 书名 → 简介标签 → 开篇 → 主线（贯穿全文的大钩子，紧扣核心看点且有拉扯空间）→ 章节（每章末小钩子：讲完但不说透，埋小高潮或伏笔）。
- 大方向钩子撑长线（废材如何崛起虐渣、男主何时识破白月光、马甲何时掉）；没有大钩子就用小钩子一环套一环（重生后即将面临困境→解决→马上抛下一个）。
- 大钩子收网时机尽量靠后，收在“整十万字”这种重要节点；不可轻易收网，要营造“事情将要发生”的错觉。

## 期待感

- 期待感本质 = 读者的 YY 感（对后续剧情的脑补与盼望）；钩子 = 期待感。
- 期待感公式：反转是期待感的前提，信息差是反转的来源。先扬后抑/先抑后扬预设结果做铺垫，让读者猜到结果如何。
- 期待感的本质是读者对剧情走向有清晰预期（虐文期待女主死心离开、爽文期待反派被打脸）；走向不清晰就没有续读欲望。
- 营造期待感两手段：人设标签化（植入固定标签，读者才会期待“发生什么”）+ 矛盾冲突（深仇大恨、情绪刻画调动期待值）。
- 满足期待的爽感路径三步：设定目标 → 完成目标 → 设定方案（高效达成并用事件填充过程）。
- 营造期待感四步（实操）：精简剧情单刀直入；小高潮衔接（一章一高潮一打脸全程无尿点）；用丰富剧情充实全书；把铺垫/设置/人设都用于放大读者期待。

## 信息差

- 信息差三类用法：主线吊点、金手指、伏笔。
- 分清四个个体——主角、配角、反派、读者各知道不同信息。
- “读者知而书中人不知”在最终爆发前是期待感，爆发时化为极端爽感（都市修仙巅峰用法）。
- 主线吊点的信息差绝不过早/过快消除，否则大量流失；大纲阶段就规划阶段性消除（多个配角依次得知真相）或多重嵌套（多重马甲，掉一个还有 N 个）。
- 作伏笔的小信息差讲究“犹抱琵琶半遮面”，给信息不给全，只做精巧细节，不要当主线钩子（否则故弄玄虚劝退）。
- 金手指型信息差，爽点必须精准落在“信息差碾压”上，别偏移成道德说教。

## 十大信息差期待模板

大战在即；遭遇强敌帮手赶来；贵人暗助；反派被主角因素打击；大佬点赞众人认可；异性敌人恋上主角；异性暗恋；获得机缘；强援到来；捡到宝物。

## 悬念与伏笔

- 悬念是短期紧张期待（不宜太长，常用“上一章设悬念，下一章就放出来，再设新悬念”）；伏笔才是长线。
- 阶段悬念法：大纲按字数分段设悬念（10w 字悬念是什么、20w 字是什么），第一个揭晓前埋好第二个伏笔。
- 言情核心悬念是感情线：男女主在一起前的暧昧最好看，一旦确定关系大批读者跑路——确定关系前必须备好下一个悬念。
- 伏笔 vs 悬念 vs 铺垫：伏笔隐性长线需呼应；悬念短期；铺垫（情节/气氛/环境）是让伏笔生效的条件。
- 伏笔六注意：大纲统筹保证前后一致；用暗示/间接方式；给足信息但不透露太多；反复强调让读者察觉不寻常但不马上给答案；有伏必有应、埋设与呼应不能脱离太久；让伏笔兼承其他作用避免刻意。
- 解谜是层次最高的钩子：把“主角要变强”升级成“主角变强顺便揭一个秘密”，比单纯爽感更耐看。

## 章末卡点

- 卡在反转前、卡在线索上，让读者自然进入下一章（“他推开门，看到的竟然是……”）。
- 下钩子要早、留提前量：换地图前、配角上下线前、新篇章展开前轻放一个钩子。
- 作者要克服“舍不得”和“耐不住”，适当屏蔽即时反馈，按节奏慢收钩子。

## 简介文案公式

背景设定 + 当前处境 + 主线目标 + 矛盾冲突 + 卖点钩子 + 反转结局。
