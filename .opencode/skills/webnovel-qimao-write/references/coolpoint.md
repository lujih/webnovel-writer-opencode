# 七猫爽感与冲突

## 爽感总则

- 故事的本质就是情绪，情绪是欲望的表现。说一个故事“平”，平的是情绪；塑造情节/人物本质都是调动情绪。
- 爽点由前置的“压”决定：写爽文像压缩弹簧，想让角色跳多高，压的幅度/深度/时间就要够。打脸不爽、搞笑轻飘，多半是困境不够扎实，解法是补困境而非削优势。
- 每写一段升级/打怪/打脸自问：“除了主角变强/赢了，读者还体验到了什么？”答不上就回头加情绪点。

## 男频爽感核心：对比

- 男频营造爽感核心方法 = 用好“对比”。
- 复仇/反击型：对比体现在主角前后实力变化 + 反派路人对主角前后态度变化；前期拉仇恨越到位（挖骨虐待嘲讽），反击爽感越强（被打败后跪地求饶）。
- “主角有，别人没有”型：主角拥有别人没有的东西（重生者的未来知识、荒野求生别人挣扎他度假），靠“有与没有”制造优越感。
- 爽点来自生活：把你觉得很爽的东西 + 对比技巧举一反三（神豪文=无限余额支付宝让看不起你的人来借钱）。

## 男频四大爽点类型

- 身份反差（以为低下实则被仰望）。
- 逆袭打脸（先把读者愤怒情绪调起来再逆袭）。
- 情感暧昧（满足征服欲）。
- 人无我有、人有我精（永远压反派一头）。

## 打脸公式

- 压主角 → 拉高情绪 → 反转 → 高潮打脸。
- 升级打法：换切入点、换被打脸对象、再加一层反转，反复调动情绪反复打脸把爽感拉满。
- 打脸/亮牌不要即时释放：让主角按捺、任反派猖狂，拖到最危急时刻才亮出，拉扯后的爽远大于即时打脸。
- 反派一条线通常要被打脸无数次才下线；单次打太狠会让读者爽完即走、长线崩盘。打脸前先浅写反派反扑趋势，把危机重新转回主角身上蓄力。
- 防爽点同质化：别照搬别人精彩剧情，剖析“它为什么精彩”提取爽点，再换剧情/设定/切入点/反派对象重新呈现。

## 升级打怪九种情绪加法

1. 给行动加阻力（实力差→恐惧/希望/绝望/酥爽，一段打斗塞四种情绪）。
2. 把奖励用透三层（捡到的满足 → 变现应用 → 变强后横向比较，比较的爽常超过升级本身）。
3. 给行动加目的（“为救病爷爷打怪”带亲情）。
4. 埋额外惊喜（超预期，关键在位置出乎意料而非贵重）。
5. 第三方反应放大爽感（震惊流，几乎零成本的放大器）。
6. 加队友（给主角一个“展示”对象，队友惊讶/依赖/感激是天然反馈）。
7. 加竞争者（比反派轻量，只需“想要同一个东西”）。
8. 加反派（抢怪/引怪/逼上交战利品制造憋屈，越气后面打脸越爽）。
9. 加解谜（层次最高）。

## 冲突与矛盾堆叠

- 矛盾冲突靠“设定”体现，而非吵架辱骂。四类：情感矛盾（虐恋/白月光）、身份立场矛盾（贫富悬殊）、观念矛盾（误会动机）、行为矛盾（明知不可为而为之）。
- 加深冲突 = 一个故事/章节内同时塑造多个相互关联的矛盾：先立最重要的主要矛盾，再衍生次要矛盾；矛盾贯穿全文，解开或破裂时情绪达顶峰。
- 竞争类冲突模板：一个争抢目标，双方都想要，抢夺爆发冲突，一方获得。烈度最大化公式：目标稀缺度极高 + 双方意愿都极强 + 都极迫切 + 都争强好胜 + 彼此关系恶劣。
- 矛盾冲突的反转要有足够力道，不是单纯套娃；每反转一次融入一重新期待感，不能流水账直接把事解决。
- 调动情绪即节奏：不断拉反派仇恨、给主角营造危机绝境，让读者捏把汗又期待反杀（被追杀→变强→再被追杀→反杀）。

## 升级体系与世界架构

- 升级体系不独立存在：先敲定世界架构核心，再从核心出发设计体系，反过来做必然悬空（历史架空核心=利益斗争走科考权谋；传统玄幻核心=以武为尊走实力）。
- 底层逻辑：量变（积累灵气/人脉/政绩/金钱/权力）→ 质变 + 随机变量（境界倒退/跨越、连胜三级、降职被贬，打破线性，否则像看进度条）。
- 升级不止实力提升：生活质量、周围人态度、伙伴资源、影响力都算升级，一条线串起所有要素联动，让读者觉得世界围着主角转。
- 三方向深挖：升级前准备（材料/能量/仪式/契机本身就是故事）、升级中危机（爆体/偷袭/强敌让提升有分量）、升级后方向（越具体获得感越实在）。
- 金手指/稀缺奖励不可滥用，否则审美疲劳写崩；升级/积累资本要一步一脚印，禁止一步登天。

## 剧情流增强爽感

- 升级向：营造对主角不利的环境（更强反派/配角嘲讽/兽潮天灾/家族偏心）逼主角变强；设置奖励（看得见=功法/系统/秘境，越稀缺期待越足；看不见=大佬赏识需提前铺垫）。爽感靠反转（扮猪吃虎、打脸）+ 主角获稀缺奖励。
- 非升级向（事业线）：前期把主角铺垫得越惨越穷（制造赚钱渴望）；搞事业给读者“画大饼”（一间铺子→开遍全国）；打脸做反转+配角工具人上演“震惊体”；制造矛盾换思路（别老用爷奶偏心）。
- 共同点：把握节奏，一步一脚印不能一步登天，太快不利拉长线、降低期待。

## 虐点与感情障碍

- 只有主角够苦读者才代入得深；感情路设困境：爱而不得、得到又失去、生离死别。
- 障碍模式：一方有意一方无情；彼此相爱却阻碍重重（误会梗、身份悬殊、长辈反对、生离死别）。
- 障碍技巧：善用配角（白月光女二、备胎男二）；巧设身份冲突（转变可作剧情突破点）；小剧情不断、撒糖之后再下刀子吊胃口；抓不同模式的吊点。
- 写虐感两要素：相对细腻的主观描写（心理+动作神色，尤其女主，放慢节奏渲染氛围）+ 相对外放的情绪表达（别太收着，适当放大清晰传递）。不到最后一刻不要轻松甜蜜相守。
- 感情线虐心写法：遭受“不公平伤害”+对比（女主伤更重却被冷漠挂电话，同时目睹男主悉心照顾女配），重点在“不公平”而非主角作死。

## 搞笑剧情

- 喜剧内核是悲剧：设悲剧对象（背锅侠，要“悲剧”非“惨剧”，否则同情心压过笑点）；配对立的获利者强化；设小丑（异想天开无实际损失者）；小丑升级为悲剧（“小丑竟是我自己”二次搞笑）。
- 正负情绪不能相加为零——调动负面情绪是好事，最怕正负抵消。玩梗≠剧情搞笑。

## 详略与关键剧情

- 关键剧情判定：对后续起强推动作用的=核心剧情（保留）；能被替代、起不到推动作用的=累赘（删）。
- 详略得当：娱乐圈文重点写“打脸”不是“拍戏”；女主进宴会先与男主/核心配角产生联系，不写场景摆设宾客名单。
- 强弱关联性原则：元素/人物/剧情/世界观/细节都要与主线强关联，弱关联题材果断砍掉；身边人物、赚钱事件、事件之间都要循序渐进（不能开局直接跟首富喝茶）。
- 经济体系四原则：货币单位与兑换符合常规认知；购买力符合常规认知；高价单位获取难度符合认知；不要过早把货币最高单位与珍贵物品等价兑换（否则后期神器无单位可换、体系崩盘）。
