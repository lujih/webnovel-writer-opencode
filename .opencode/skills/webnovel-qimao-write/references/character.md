# 七猫人物与对白

## 人设基础

- 先固人设再推剧情：先做完整人物背景（终极目的 + 当下短期困境/目标），再依性格推剧情。绝不为套预设桥段扭曲人物——这是防一切人设崩塌的根。
- 稳定的内核（人设稳定）是爆款必备；人设转变必须与关系进展适配，不得违背开篇基调。
- 人设三维度：生理特征（姓名/年龄/外貌/身高，直白概述）+ 社会维度（家庭+职业，职业要明确且能挂事业线）+ 主观心理（性格/能力/爱好/三观，最重要、靠剧情表现）。
- 性格只能靠剧情展现不能干说：偏执男主→看到女主跟别的男人聊天就吃醋；高冷男主→对谁都冷只对女主暖。
- 主角人设五点：外表（有记忆点，女频认“美强惨”）、姓名（贴合人物、朗朗上口、忌生僻字）、性格反差、背景（金手指写“强”、困境写“惨”，惨≠血呼啦差）、动机（行为符合性格逻辑）。

## 鲜活与记忆点

- 鲜活三阶：起步=明确基本性格；进阶=加个性化小设定（爱好/口头禅/习惯动作，反复提及强化记忆）；精通=反差设定（杀神爱吃苹果的黄毛）+ 随剧情成长迎高光时刻。
- 写人要有记忆点而非写“照片”：与其堆两三百字外貌，不如几笔勾勒个性，其余留给想象。
- 反差萌：选一个主要特质发挥到极致，再叠加反差特质（清冷高岭之花对女主耳根通红、武力高但痛觉敏感），反差不能破坏整体一致性。
- 写美人造“氛围感”：加场景加道具、用侧面描写；现言可专挑一个部位（如脖颈）全文多次赞美成记忆点（别过多）。
- 身份职业创新+马甲信息差：跳出珠宝/服装设计师老套路，用文物修复师、小提琴家、乡医、法医、入殓师等；不熟的职业少写专业细节。
- 特殊设定造独一无二 CP 感：失眠男主唯独遇女主秒睡、夜盲症唯独夜里能看清女主。

## 防人设崩塌

- 心理维度最易崩。高冷男主吃醋必须等爱上女主之后才合理；飒爽女主不能受欺不还手、被害还圣母原谅。
- 设定一旦定好，言行处世从一而终。
- 不要为制造冲突强行把人物写降智——逻辑崩、情绪脱节是头号崩文原因。
- 读者都有“厌蠢症”：绝不让主角犯低级错误。
- 主角必须有主观能动性，主动触发推动事件，不能全程被剧情推着走。

## 配角

- 一切配角为衬托主角；立场分正面（导师/协助/爱慕）、中立（神秘/竞争/丑角）、负面（陷害）。
- 正面力量太强→危机感不足；负面力量太强→主角地位崩。必要时可降反派智商衬托主角。
- 配角批量设计三步：以主角为中心占坑（近兄弟亲人、远中立、最远反派，可设表里身份反转）；同阵营做差异化对比（军师聪明则逗逼迟钝）；搭角色关系网让任意组合同场都有戏。
- 每阶段主要反派配角 2-3 个即可，解决一批进下一阶段再出新配角。
- 配角不贴语境读者会觉得别扭弃文；笔墨过多又会喧宾夺主。

## 黑化与洗白

- 黑化不是替换性格，是 B 面撑破 A 面；功夫在黑化之前——前期写实“压制机制”，让读者看到 B 面早就在。
- 黑化四契机：挚友爱人惨死；付出太深被抛弃；真相曝光认知垮掉（前期写主角“主动选择相信”）；反复被欺压到临界点。
- 半黑化（踏进去一半、只对真敌动手不伤无辜）的悬念比全黑化更揪心。
- 洗白五法：立场对立型、被操控非自愿型、救赎型、信息差型（被栽赃/卧底）、卖惨型。
- 洗白有度：对主角团伤害太重结成血仇就洗不动；救赎型只能从黑洗到灰，洗白是转折点不是漂白剂。

## 代入感

- 代入感本质 = 情感共鸣（更好地传递情绪），不是角色贴近现实。核心剧情不能只有“事件”没有“情绪”。
- 提代入感四法：核心剧情要有能共鸣的情绪/爽点；言情开篇多用女主视角写所见所感所想；叙事清晰是底线，删对情绪无影响的描写；适当侧面描写（下属神色表现男主生气）。
- 女频文聚焦女主视角、少写男主心理，靠揣测男主意图制造博弈感；大篇幅写男主内心是“焦点偏移”，冲淡代入感。
- 接地气提升代入感：切入点越接地气越好（婚恋痛点、相亲），抛弃抽血挖肾灭全族的脱离实际炸裂梗。

## 对白与句式

- 优先短句、短段、强节奏；单段尽量 1-3 句；爽点/反转/悬念/强情绪单独成段。
- 每句对白都要有作用：推进剧情/制造冲突/塑造人物/暴露关系/传递信息/制造爽点或悬念。
- 禁止说明书式对白和无效寒暄；保留潜台词，连续对白穿插动作、眼神、停顿。
- 对话要凝练且符合人设（高冷总裁别话痨）；对话要有信息量，把关键信息和矛盾放进对话。
- 展示而非讲述：性格情绪靠压力下的选择/行动/关键对话表现，避免大段内心独白。
- 心理描写三原则：写特定人物在特定环境必然产生的心理；只在关键情节/动作/表情时伴心理描写；写细微感情波澜的变化过程。
