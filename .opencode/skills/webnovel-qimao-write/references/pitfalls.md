# 七猫避雷与改稿

## 改稿与数据

- 改稿先看数据，再看评论，再动结构；盲目改文是无用功，先系统梳理复盘（人物/情节/环境三要素）。
- 章节问题和大纲问题分开处理：只影响本章表达的改本章；影响因果/人物动机/主线方向的回大纲。
- 变更后重读一遍，避免越改越乱。
- 善用多方资源：读者反馈（多数读者反馈同一问题大概率真有问题）、责编/同行意见、作品数据（扩大优势剧情、减少短板剧情）。

## 标题与承诺

- 书名、简介、开篇承诺的卖点，正文必须尽快兑现；开篇就围绕书名+简介这两个期待点展开。
- 章节标题对应核心事件/悬念/收益，不要只追气氛；章节名剧透过多会致单章被点读、影响留存判断。
- 改书名要谨慎，会流失前期积累读者。

## 书名技巧

- 三标准：定位作品风格分类吸引对应读者；简洁易读贴合文风，不超过 15 字（含标点）；忌涉黑涉政涉黄、忌书名与内容割裂、忌晦涩生僻字。
- 取名要带情绪，平铺陈述句不可取；词穷就用各题材固定关键词库 + 看点设定组合；取名先扫榜。
- 主语选择决定侧重：女主主语=女主能动性强；萌宝主语=萌宝推动剧情；男主人设主语=用反差感造期待。

## 常见毒点（导致留存崩）

- 首屏没有目标、冲突、异常、危机、羞辱、悬念或金手指之一。
- 开头连续解释背景/设定/前史/家族谱系/规则，信息轰炸。
- 主角迟迟不行动，只被动接收信息；或被强行降智犯低级错误。
- 冲突只有口头“很难”，没有具体对手、代价、时间压力、规则限制或资源缺口。
- 爽点只有主角赢了，没有旁人反应、敌人代价、局势改变或收益到账。
- 连续多章只铺垫不兑现，或章末平收。
- 配角工具人、反派无逻辑、单场景乱切视角。
- 无关/惹厌配角单独描写过多（喧宾夺主）。
- 剧情流频繁写感情戏、感情流疯狂剧情升级（笔墨不均、基调游离）。
- 过渡章过于平淡、无爽点无钩子。
- 同质化照搬（至尊卡打脸、高手下山三件套、下山保护女总裁），读者已麻木会跳章。
- 字词雷点：错字、标点错误劝退读者；主要角色姓名忌生僻字；生僻字/网络用语控制频率。

## 六大崩文场景

1. 心血来潮无大纲（写着写着飞了）。
2. 换地图脱离主线（不先埋钩子硬切）。
3. 人设崩塌（配角不贴语境、主角降智）。
4. 节奏失控（前面高光后面水文）。
5. 核心人物下线过快 / 大钩子放太早。
6. 剧情线情感线双线割裂（无铺垫来回切换，两批读者都流失）。

崩文本质都是没做好钩子、没拉好期待、没挖好坑。先想清要写什么故事、谁是核心人物、什么是主线钩子，基本就能避开。

## 常见改稿方向

- 开头慢：提前冲突、提前目标、压缩背景、看点前置。
- 冲突弱：加代价、加对手主动性、加时间压力、加信息差。
- 爽点轻：补旁人反应、敌人代价、局势改变；先查困境够不够扎实。
- 过渡空：补后果、补转移、补新危机、补关系变化。
- 结尾软：补危机、选择、秘密、反转、新目标或未兑现奖励。
- 节奏太慢：删重复解释、压缩无效过渡、合并相似场景。
- 节奏太快：补必要铺垫、角色反应、代价、反馈、因果桥。

## 编辑拒稿模板潜台词

- “文笔待提升” = 直白叙述需细节化（“她哭得很伤心”→蜷缩墙角、指甲掐进掌心）。
- “细节力度弱” = 描写停在表面。
- “开篇切入点缺乏吸引力” = 平铺直叙背景开场。
- “节奏拖沓” = 无关描写多、矛盾堆砌不围绕主要矛盾。
- “缺钩子悬念” = 缺大钩子和章末卡点。
- “视角混乱/主角存在感弱” = 配角戏份挤压主角。
- “人物不立体/脱离现实” = 行为单一或逻辑矛盾无解释。
- “主角主观能动性弱” = 被剧情推着走。

## 必要性审查法

每段每句每词都问：是否推动情节（离目标近/远一步）/塑造人物/揭示核心设定/营造当前场景核心情绪/服务读者核心期待。都不是 → 坚决删除。

## 微创新

- 微创新 = 在传统成熟套路下对人设与情节创新，且必须让大部分受众能接受（受众有限的创新不要）。
- 人设方向：人物关系创新（无血缘亲属/渣男配与女配无血缘）；身份职业创新（该题材不常见职业、本身小众职业如法医入殓师）。
- 情节方向（仅指开头切入）：必须先把模糊设定具象化为“具体事件”——不是“渣男爱白月光”，而是“渣男把女主最爱的项链送了白月光”。两路：生活化（细腻日常调情绪）/夸张化（狗血戏剧性、常涉生死）。
- 二八定律：20% 书成爆款、80% 扑街；新人主攻第二梯队（套路文+微创新）。

## 扫榜

- 两目标：写开篇→扫开头；写套路文→扒框架（看结尾、扒框架防崩文）。
- 三态度：抛开个人喜好从写文者角度找市场热点；数量不能太少；找优点而非找缺点（思考有硬伤的文为何能上榜）。
- 诀窍：会总结规律（泛滥题材可能饱和别碰、中不溜和少的可试）；以扫新文为主（几十万字新文时效强）；扫不出就看评论区长评/加精评论。

## 心态

- 网文收入与内容强相关、与其他因素弱相关，劲往内容上使。
- 收入本就波动（开新书前十几二十万字不赚钱），别用单月成绩定义自己，改用年度目标看。
- 好内容是成绩下限保证；心态稳→专注码字→写得更好→成绩涨→更自信，良性循环。
- 有差评不可能人人喜欢，敢面对质疑、正确归因，给差评的读者也是被你的文调动了情绪。

## 保持长篇激情

- 把写作流程固定成习惯（固定时间/地点/软件/字数，有仪式感）。
- 动笔前做好设定+大纲框架（设定=设计图，大纲=地基，百万字拆小块按步完成）。
- 不断更新认知（多阅读扫榜、记录素材，蓄水池理论）。
- 正向激励（给自己每次进步奖励，加速多巴胺）。

## 灵感与卡文

- 灵感素材三条件：生活性、冲突性、戏剧性；让素材产生戏剧性三操作：人物行为反转、人物身份反转、情节骤变。
- 卡文实战法（小说三要素改造）：拿一个热点作骨架→改人物（换身份+加设定）→改情节（角色互换、换视角、加脑洞）→改背景（微观场景/宏观背景），发散多个故事挑最合适的。
- 蹭热点六标准：有同理心（别吃人血馒头）、符合国家规定、适合大部分人、噱头强、热点持续时间长、能引起共鸣产生情绪。
- 随时记录积累灵感，灵感稍纵即逝。
