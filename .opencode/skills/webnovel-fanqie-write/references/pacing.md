# 番茄节奏

## 开书与大纲

- 先用一句话概括故事：谁、什么处境、为了什么、面对什么阻碍、最终变化是什么。
- 开书前先明确题材、读者需求和主卖点。
- 大纲要分层：全书主线、分卷目标、阶段任务、章节功能。
- 核心纲负责方向，设定集负责规则、边界、代价和例外。

## 题材判断

- 题材要能持续产出，不要只追热度。
- 题材辨识度至少来自一个：主角身份、金手指、世界规则、核心矛盾、情绪爽点、关系结构、叙事视角。
- 跨题材混搭要有主次，不能每种都想占满。

## 开篇

- 第一章：处境 + 核心冲突/异常 + 卖点。
- 第二章：冲突扩大 + 规则/代价 + 明确目标。
- 第三章：小兑现或强悬念 + 下一阶段问题。
- 前三屏尽快给出处境、目标、异常点或矛盾点。

## 章内

- 默认单章目标 `2000-2500` 中文字符。
- 过渡章可以略短，但不能长期低于 `2000`。
- 每 500 到 800 字至少有一次信息、情绪、局势或关系变化。
- 中段至少一次局势/情绪/信息变化。
- 结尾必须留下一句还能接下一章的问题。

## 过渡章

- 不能只写赶路、闲聊、解释设定。
- 必须承接后果、转移目标、埋新危机、推进关系或蓄力冲突。
- 过渡章要保留轻冲突或隐性压力。

## 中期瓶颈

- 不能连续铺垫。
- 要靠伏笔、配角变量、目标转移或局势升级制造新问题。
- 时间线、支线、副本要定期交汇并回收信息。
