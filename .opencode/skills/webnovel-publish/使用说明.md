# webnovel-publish 使用说明

## 概述

`webnovel-publish` 将四个独立脚本（`fanqie_publish.py`, `qimao_publish.py`, `clean_drafts.py`, `clear_drafts.py`）的功能合并进了 `publisher/` 模块体系，统一通过 `webnovel.py publish` 子命令调用。

## 功能对照表

| 原脚本 | 新命令 | 功能 |
|--------|--------|------|
| `fanqie_publish.py login` | `webnovel.py publish setup-auth --platform fanqie` | 扫码登录 |
| `fanqie_publish.py list` | `webnovel.py publish list-books --platform fanqie` | 列出书籍 |
| `fanqie_publish.py upload` | `webnovel.py publish upload --platform fanqie` | 上传章节 |
| `fanqie_publish.py delete` | `webnovel.py publish delete-drafts --platform fanqie` | 删除全部草稿 |
| `fanqie_publish.py publish` | `webnovel.py publish publish-drafts --platform fanqie` | 发布草稿 |
| `clean_drafts.py` | `webnovel.py publish clean-drafts --platform fanqie` | 清理重复草稿 |
| `clear_drafts.py` | `webnovel.py publish clear-drafts --platform fanqie` | 清空草稿箱 |

## 快速开始

### 1. 首次使用：登录

```bash
python .opencode/scripts/webnovel.py publish setup-auth --platform fanqie --project-root .
```

浏览器会弹出番茄小说作者后台，扫码登录后认证状态自动保存到 `~/.webnovel-publish/browser_data/fanqie/`。

### 2. 查看书籍列表

```bash
python .opencode/scripts/webnovel.py publish list-books --platform fanqie --project-root .
```

获取你账号下的所有书籍和对应的 `book_id`。

### 3. 上传章节

```bash
# 上传全部章节
python .opencode/scripts/webnovel.py publish upload \
  --platform fanqie \
  --book <book_id> \
  --project-root .

# 上传指定范围
python .opencode/scripts/webnovel.py publish upload \
  --platform fanqie \
  --book <book_id> \
  --range 1-10 \
  --project-root .

# 跳过确认（脚本环境）
python .opencode/scripts/webnovel.py publish upload \
  --platform fanqie \
  --book <book_id> \
  --yes \
  --project-root .
```

**断点续传**：已上传章节会自动跳过，上传日志存储在 `~/.webnovel-publish/upload_log/`。

### 4. 草稿管理

#### 清理重复草稿

适用场景：多次上传同一章导致草稿箱有重复，想保留最新版本删除旧版本。

```bash
# 预览模式（不实际删除）
python .opencode/scripts/webnovel.py publish clean-drafts \
  --platform fanqie \
  --book <book_id> \
  --project-root . \
  --dry-run

# 执行清理
python .opencode/scripts/webnovel.py publish clean-drafts \
  --platform fanqie \
  --book <book_id> \
  --project-root .
```

#### 清空草稿箱

适用场景：想清空草稿箱重新开始，但不删除已正式发布的章节。

```bash
python .opencode/scripts/webnovel.py publish clear-drafts \
  --platform fanqie \
  --book <book_id> \
  --project-root .
```

#### 删除全部草稿

**危险操作**：会删除所有草稿（包括已发布状态的章节），并清除上传记录。

```bash
python .opencode/scripts/webnovel.py publish delete-drafts \
  --platform fanqie \
  --book <book_id> \
  --project-root .
```

需要输入 `yes`（而不是 `y`）进行二次确认。

#### 发布草稿

适用场景：章节已在草稿箱，想批量发布到正式站。

```bash
# 发布指定范围
python .opencode/scripts/webnovel.py publish publish-drafts \
  --platform fanqie \
  --book <book_id> \
  --range 1-10 \
  --project-root .

# 发布全部草稿
python .opencode/scripts/webnovel.py publish publish-drafts \
  --platform fanqie \
  --book <book_id> \
  --project-root .
```

## 项目绑定

首次 `upload` 或 `create-book` 成功后，book_id 会自动绑定到项目的 `.webnovel/publish_config.json`。后续操作可以省略 `--book` 参数：

```bash
# 绑定后可以这样调用
python .opencode/scripts/webnovel.py publish upload --platform fanqie --project-root .
```

## 技术说明

### 代码结构

```
.opencode/scripts/publisher/
├── __init__.py              # CLI 入口，包含所有子命令实现
├── adapters/
│   ├── fanqie.py           # 番茄小说 adapter（新增草稿管理方法）
│   └── qimao.py            # 七猫小说 adapter
├── browser.py              # Playwright 浏览器管理
├── config.py               # 配置和日志管理
└── formatter.py            # 文本格式化

.opencode/skills/webnovel-publish/
└── SKILL.md                # 技能说明文档
```

### 新增方法（fanqie.py）

1. **`get_all_drafts(page, book_id)`** - 全量获取草稿箱章节列表（支持分页）
2. **`delete_draft(page, book_id, item_id)`** - 删除单个草稿
3. **`publish_draft(page, book_id, item_id, title, content)`** - 发布草稿

### 新增子命令（__init__.py）

1. **`clean-drafts`** - 清理重复草稿（同章节号保留最新修改时间的）
2. **`clear-drafts`** - 清空草稿箱所有章节（跳过已发布）
3. **`delete-drafts`** - 删除草稿箱全部章节（危险操作）
4. **`publish-drafts`** - 发布草稿箱中的章节

### 备注说明

所有草稿管理功能都在代码中标注了来源：

```python
# ── 草稿管理 ─────────────────────────────────────────
# 来源：合并自根目录的 fanqie_publish.py, clean_drafts.py, clear_drafts.py
# 功能：获取草稿列表、删除草稿、发布草稿、清理重复草稿
```

## 常见问题

### Q: 旧脚本还能用吗？

A: 不能。`fanqie_publish.py` / `qimao_publish.py` / `clean_drafts.py` / `clear_drafts.py` 已删除，功能已完全合并进 `publisher/` 模块。

### Q: 如何从旧脚本迁移？

A: 参考上面的"功能对照表"，命令参数基本一致：
- `--book <id>` → `--book <id>`
- `-y` / `--yes` → `--yes` / `-y`
- `--dry-run` → `--dry-run`

唯一区别是需要加上 `--platform fanqie` 和 `--project-root .`。

### Q: 认证状态存在哪里？

A: `~/.webnovel-publish/browser_data/<platform>/`，删除该目录可重新登录。

### Q: 上传记录存在哪里？

A: `~/.webnovel-publish/upload_log/<project_name>/<platform>_<book_id>.json`

### Q: 草稿管理对七猫平台支持吗？

A: 目前仅番茄平台（fanqie adapter）实现了草稿管理方法。七猫平台（qimao adapter）需要补充相同的三个方法才能支持。

## 扩展其他平台

如需为七猫或其他平台添加草稿管理功能，参考 `publisher/adapters/fanqie.py` 的实现，在对应 adapter 中添加：

```python
async def get_all_drafts(self, page, book_id: str) -> list[dict]:
    # 实现草稿列表获取

async def delete_draft(self, page, book_id: str, item_id: str) -> bool:
    # 实现草稿删除

async def publish_draft(self, page, book_id: str, item_id: str, 
                       title: str, content: str) -> bool:
    # 实现草稿发布
```

然后 `__init__.py` 中的四个草稿管理子命令会自动支持该平台。
